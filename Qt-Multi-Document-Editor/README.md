# 多文档文本编辑器

使用 Qt 6.9.1、C++17 和 Qt Designer，作者：郑亚泽。

## 打开与运行

在 Qt Creator 中打开本目录的 `CMakeLists.txt`，选择 Qt 6.9.1 MinGW 64 位套件，构建并运行。
也可以在 PowerShell 中运行 `.\build.ps1` 构建和测试，再运行 `.\run.ps1`。详见[仓库的构建说明](../README.md)。

双击 `mainwindow.ui` 可在 Designer 中调整欢迎页、菜单栏、工具栏和灰色多文档工作区。
文档子窗口由 C++ 动态创建，字体下拉框和字号输入框在工具栏中由代码添加。

## 功能

- 欢迎界面、作者署名，隐藏按钮焦点虚线框。
- 新建、打开、保存、另存为多个文档。
- 选中文字后设置字体、字号、粗体、斜体和下划线。
- 没有选区时设置后续输入的格式。
- 撤销、重做、剪切、复制、粘贴、全选。
- 查找下一个、替换当前、全部替换，查找到末尾后从开头继续。
- 左对齐、居中、右对齐。
- 子窗口层叠、水平平铺（上下排列）、垂直平铺（左右排列）。
- 修改星号、未保存提示，保存失败或取消保存会阻止关闭。

## 文件格式

Windows 上新建文档首次保存时默认选择 RTF。通过“文件 → 打开”可以打开 `.rtf`，编辑后按 `Ctrl+S` 保存到原文件。

- RTF 保留中文、字体、字号、粗体、斜体、下划线、颜色和段落对齐。读写使用 Windows 自带的 Rich Edit，直接在 Qt 界面中编辑。
- HTML 可保存带格式的内容。
- TXT 使用 UTF-8 编码，仅保存文字。

RTF 支持课程示例中的基础文字排版。含图片、表格或嵌入对象的 RTF 会提示无法导入。RTF 每个文件最多 8 MB，正文最多 25 万个 UTF-16 代码单元。


## 代码阅读顺序

1. mainwindow.ui：界面控件、菜单和操作名称。
2. main.cpp：程序入口及隐藏焦点框的样式。
3. mainwindow.cpp：连接按钮与功能，管理活动文档，设置文字格式，排列窗口，查找替换。
4. documenteditor.cpp：单个文档的读取、保存、标题以及关闭提示。
5. rtfcodec.h/.cpp：Windows Rich Edit 与 Qt 文档之间的格式转换。
6. tests/editor_test.cpp：中文读写、RTF 格式往返、文档独立性和窗口排列测试。

界面对象使用清晰名称，算法中的循环计数使用 i、n 等短变量名，关键逻辑附中文注释。
