# Qt C++ 计算器

这是一个使用 Qt 6 Widgets 和 C++17 编写的桌面计算器，界面使用可由 Qt Designer 编辑的 `mainwindow.ui` 文件。

## 功能

- 加、减、乘、除、取模、开根号、倒数和连续运算
- 小数、正负号、退格、清空
- 除数为 0 和数值溢出提示
- 支持鼠标和键盘输入
- 左右括号、嵌套括号和运算优先级：先括号，再乘除取模，最后加减

点击 `(`、`)` 按钮或用键盘输入括号，按等号计算。例如 `2*(3+4)=14`、`(2+3)*4=20`。
`2(3+4)` 会自动补成 `2×(3+4)`。括号未闭合会显示错误，可用退格修改；输入数字会开始新计算。
开根号、倒数和正负号作用于末尾的数字或完整括号，例如输入 `2+(3*3)` 后按开根号，再按等号得到 5。
表达式过长时显示末尾部分，鼠标悬停可查看完整表达式。

键盘可使用数字、`+ - * / %`、回车和退格，其中 `%` 表示取模；`Esc` 或 `Delete` 清空。

## 编译运行

也可参照[仓库的构建说明](../README.md#用-qt-creator-打开)。

在 PowerShell 中进入本目录后运行：

```powershell
.\build.ps1
.\run.ps1
```

也可以用 Qt Creator 打开 `CMakeLists.txt`，选择 Qt 6.9.1 MinGW 套件后直接构建。

## 文件说明

- `main.cpp`：创建 Qt 应用和主窗口。
- `mainwindow.h/.cpp`：计算器面板、按钮事件和输入状态。
- `calculatorengine.h/.cpp`：表达式解析和基础数学运算。
- `tests/`：运算优先级、异常表达式和按钮、键盘交互测试。

算法中的 `x`、`y`、`ans` 分别表示两个操作数和答案。Qt 控件使用 `displayLabel` 等名称，与 Designer 的对象查看器对应。
